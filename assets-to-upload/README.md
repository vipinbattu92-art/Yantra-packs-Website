# Asset Upload Staging Area

Drop your files into the correct subfolder below. Any filename/format is fine — I'll rename, resize, and move them to the right place automatically.

---

## 📁 logo/
Drop your **main brand logo** here.
- Accepted: `.svg`, `.png`, `.jpg`
- Recommended: SVG (scales perfectly at all sizes)
- Used in: navbar on all pages
- Example filename: `yantra-packs-logo.svg` or `logo.png`

---

## 📁 favicon/
Drop your **favicon source** here.
- Accepted: `.svg`, `.png`, `.ico`
- If you have the full logo, I can derive a favicon from it
- Used in: browser tab icon
- Example filename: `favicon-source.png`

> If you have no separate favicon asset, just leave this empty — I'll create one from the logo.

---
